# Codex Token 状态条

Windows x64 浮条，自动跟随 Codex 桌面版当前聊天。

![Codex Token 状态条预览](docs/images/statusbar.png)

## 怎么用

1. [下载安装包](https://github.com/3ALLBUY14/codex-token-statusbar/releases/latest)，完整解压后双击 **安装.cmd**，点击「安装并启动」。便携使用可直接运行 app 目录里的 **CodexTokenStatusbar.exe**。
2. 打开 Codex 桌面版，进入聊天。点击浮条的 **C** 查看明细，点击 **⚙** 打开设置。

## 功能

- 查看 Token 用量、轮次均速和上下文占用。展开后可看缓存输入、推理输出等分项。
- 每 5 分钟刷新 Codex 官方额度，显示剩余比例和重置时间。ChatGPT Pro 只显示周额度。
- 查看每日用量趋势、热力图、各模型用量及请求和工具调用明细。
- 自定义浮条位置、贴靠、透明度、主题和指标顺序，支持新版本通知。
