速度怎么算

上一轮输出 Token ÷（轮次耗时－首 Token 延迟）。缺少首 Token 时间时按完整耗时计算。包含推理输出、工具执行和多次模型调用，因此标记为平均输出速度，而不是纯模型生成速度。

所有统计来自本机日志，缓存输入和推理输出不会重复计入总量。这里的 Token 用量不等同于套餐额度或账单。
