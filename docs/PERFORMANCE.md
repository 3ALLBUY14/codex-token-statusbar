# V1.3 性能验证

2026-10-15 在本机 Windows x64 上测量。以下结果用于比较实现，不能代表所有电脑。

## 窗口助手

运行 `npm run benchmark:helper`，每种助手各启动三次，记录进程启动至首次有效窗口数据的时间；首次数据后等待约 2.2 秒，再采集相关进程的工作集和累计 CPU 时间。独立助手计入坐标与标题两个进程。测试时 Codex 不在前台，因此标题通道处于空闲状态，这不能证明活跃 UI Automation 查询的 CPU 消耗。

| 项目 | 独立助手 | PowerShell 兼容助手 |
| --- | ---: | ---: |
| 首次有效数据，中位数 | 69 ms | 1042 ms |
| 首次数据，三次测量 | 69 / 82 / 59 ms | 1124 / 1042 / 1040 ms |
| 工作集合计，中位数 | 约 45.7 MiB | 约 84.1 MiB |
| 短时间累计 CPU，中位数 | 0.219 s | 1.734 s |

工作集可能包含共享页面，并非独占物理内存；CPU 是启动及短时间运行的累计值，不是长期占用率。结果不包含主 Electron 应用，也不等于聊天切换时延。

`npm run verify:helper` 另行验证真实坐标采样、标题空闲心跳与父进程退出后的清理。单元测试覆盖标题通道超时不影响坐标、窗口切换后迟到标题、连续启动失败回退和停止后的重启取消。本机 Codex Desktop 26.1007.9446.0 的文档标题读取与本地索引唯一匹配已验证；真实多显示器、不同 DPI 之间来回移动仍需更多硬件验证。

## 分享包

原版包含 55 个 Chromium 语言包，共 50,643,495 字节。V1.3 仅保留 `zh-CN.pak` 与 `en-US.pak`；不删 ICU、GPU、视频组件或授权文件。打包时将实际移除数量和字节数写入本地 `artifacts/package-size-report.json`，该报告和真实本机日志均不进入发布包。

源码与打包版分别执行界面 smoke 检查，包含中文显示、窄窗口布局、设置保存及工具明细。新增语言的支持应同时调整保留列表和打包测试。
